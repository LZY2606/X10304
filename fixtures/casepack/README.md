# 证明轨迹台 · 离线案例包（SAT DRAT 子句、传播链与失败前缀）

本目录是形式验证小组的离线案例包，不是通用表格：

- `baseline.cnf` / `baseline.drat`：基线来源。导入时保留原 DIMACS token、
  变量编号、每条 proof 行、子句多重集、解析偏移与资源预算。
- `casepack.json`：机器可读的档案清单。每个变异只改动一个直接来源，
  覆盖：重复子句、tautology、RAT pivot、多次删除、缺零终止、超大变量编号、预算耗尽。
- 叙事场景：一次参数修订（传播预算 64→1）、一次只影响局部依赖的源数据改动、
  一次互相冲突的人工决定（RAT pivot 候选的取舍）。

判定语义：RUP 与 RAT 检查区分；删除不存在子句不改变集合但留诊断；
tautology、重复 literal、零终止按语法处理；资源耗尽不是证明无效。
